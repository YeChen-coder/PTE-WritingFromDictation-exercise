一切事情的起因，都归功于作者希望节奏能快一点，不想每听写一次都要点好几下。

所以就做成了这样：这 100 多个 Write from Dictation 题目，发音念一遍，用户这边哐哐打，打完觉得差不多了直接按回车。如果全对，就自动跳到下一题；如果有问题，中间的结果反馈区会做逐字对比，直接标出哪里有错。

另外，错题题号是会自动记录的，也可以只练错题（左边有一个“开始错题训练”的选项）。

但有一点需要特别注意：
程序开着的时候，错题会一直积累；但它不会持久化保存。如果把整个程序关了、电脑重启了、或者浏览器重新打开了，之前错的题号就不会记录了。

看一下下图，错题对比以及错题本的记录，大概是这个样子。

左边“训练控制”这边包括但不限于：

1. 音频结束后的倒计时时间
2. 全对后是否自动进入下一题
3. 是否播放激励音效，以及各种音效的音量设置

这些都可以修改。那个激励音效是因为作者本人挺需要被激励的，所以自己找了一段音频作为激励音效，大家也可以根据需要自己改，都没关系，无所谓的
